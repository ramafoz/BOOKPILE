# Archived BOOKPILE documentation

The files in this directory preserve design history, completed phase detail,
superseded inventories, accepted checklists and earlier repository landing
pages. Nothing is deleted merely because it stopped being current: this is the
project's archaeological record.

These files are not active roadmaps or operational instructions. Their
checkboxes, progress percentages, provider choices, quotas, commands and dates
may be obsolete. Follow links back to active runbooks before acting on them.

Current work and release status exist only in
[`../BOOKPILE_MASTER_WORK_PLAN.md`](../BOOKPILE_MASTER_WORK_PLAN.md).

Notable snapshots include:

  original conversation that started BOOKPILE.
- [`README-pre-housekeeping-2026-11-25.md`](README-pre-housekeeping-2026-11-25.md)
  — the former 605-line root README preserved before documentation cleanup.
- [`SERVER_STAGING_PROVISIONING_CHECKLIST.md`](SERVER_STAGING_PROVISIONING_CHECKLIST.md)
  — the completed initial staging provisioning and acceptance record.
- [`SERVER_DEFENSIVE_SECURITY_INVENTORY.md`](SERVER_DEFENSIVE_SECURITY_INVENTORY.md)
  — the D1 inventory written before the later D2–D7 controls were completed.
- [`phase4d-local-reuse-audit.md`](phase4d-local-reuse-audit.md) — the completed
  Local-to-Server physical-map reuse audit.
